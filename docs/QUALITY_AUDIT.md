# 创世谷 Quality Audit（第 1 轮）

> 依据：代码审查 + 用户实机反馈（加载卡 30%、着色器报错、村民倒走、画面糊）。
> **尚未有实机截图与帧率数据**——视觉 / 手感类结论都是"待实机确认"。下一轮以「Genesis Valley › 质量采集」输出的
> `contact_sheet.jpg` + `report.md` 为准，逐条确认或推翻本表。
>
> 引擎说明：本项目是 **团结引擎 1.10.4（Unity 2022.3）+ URP 14**，不是 UE5。Master Prompt 中的 UE 术语按等价物处理：
> Niagara → ParticleSystem（`FxLibrary`），Lumen/Nanite → URP 烘焙/实时光 + LOD，Replication → 房主权威命令同步（GDD §14）。

## 本轮已处理

| 级别 | 问题 | 处理 |
|---|---|---|
| P0 | 标题世界加载卡在 30%（`Instantiate` 空对象，协程无保护） | `WorldPresenter.Bind` 分层容错；`FxLibrary` 模板为空时跳过 |
| P0 | `GVFoliage` / `GVVertexLit` ShadowCaster 编译失败（`LerpWhiteTo`） | 补 `CommonMaterial.hlsl` |
| P0 | `OnTerrainChanged` 与 Unity 内置消息冲突 | 改名 `OnTerrainRegionChanged` |
| P1 | 村民倒着走 | 动画导入改用 Body Orientation，导入规则 v5 强制重导 |
| P1 | 游戏中画面发糊 | 游戏内景深改为"只虚化远处"的 Gaussian；拍照模式保留 Bokeh |
| P1 | 镜头只检测镜头正下方的地面，山丘会挡住视线 | 沿整条视线采样地形并平滑抬升 |
| 流程 | 无法获得实机证据 | 新增「质量采集」：固定种子 → 模拟 2 天 → 3 镜头 × 4 时段 + 地形改造前后 + HUD 截图 + FPS / Draw Calls / 内存 + 全部报错 |

### P1（体验）
| 问题 | 说明 | 建议 |
|---|---|---|
| 地形工具只有 抬升 / 降低 / 平整 / 河流 | 缺 Smooth、Path、Terrace、Cliff；"雕刻世界"的手感单一 | 先补 **平滑** 与 **小路**（村民寻路代价降低，直接影响 NPC 路线 = 世界回应），再做台地 |
| 地形变化是即时上传 | 没有"逐渐隆起"的过渡、没有土层 / 碎石显露 | 高度上传加 0.2–0.4 s 插值；陡坡与新挖处混入土 / 岩层权重并散落碎石 |
| 玩家无法直接放置建筑 / 道路 | 现在是 VillagePlanner 自动建村（GDD 的上帝视角设计） | **需要你拍板**：保持"引导村民建设"（加规划区 / 意向标记），还是加入玩家直接摆放。两者影响整个循环，不能由我单方面决定 |
| 村民日程只有 闲置 / 走路 / 工作 / 睡觉 | 没有社交、聚集、吃饭场所、广场、天气反应 | 在 Utility AI 加"傍晚篝火 / 广场聚集"和"清晨出门"两个行为，最便宜、最显"活" |
| 镜头无建筑遮挡处理 | 近景时房屋会挡住村民 | 近距离时对遮挡建筑做淡出（需实机确认程度） |
